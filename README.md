### Featured Project — S.I.G.A.P

> **Sistem Informasi Gempa &amp; Aksi Penyelamatan**  
> Full-stack earthquake disaster-mitigation platform (Backend + Mobile) built for a national App Dev competition.

<p>
  <img src="https://img.shields.io/badge/Python-151515?style=flat-square&logo=python&logoColor=white" alt="Python" />
  <img src="https://img.shields.io/badge/FastAPI-151515?style=flat-square&logo=fastapi&logoColor=009688" alt="FastAPI" />
  <img src="https://img.shields.io/badge/PostgreSQL_%2B_PostGIS-151515?style=flat-square&logo=postgresql&logoColor=4169E1" alt="PostgreSQL" />
  <img src="https://img.shields.io/badge/Docker-151515?style=flat-square&logo=docker&logoColor=2496ED" alt="Docker" />
  <img src="https://img.shields.io/badge/Kotlin_Compose-151515?style=flat-square&logo=kotlin&logoColor=7F52FF" alt="Kotlin" />
</p>

<table align="center" style="max-width: 720px; text-align: left;">
  <tr>
    <td style="padding: 16px 22px; background-color: #151515; border: 1px solid #2d2d2d; border-radius: 8px;">
      <ul>
        <li><b>RAG-Powered Disaster Education</b> — Multilingual embeddings &amp; LLM Q&amp;A for pre-disaster literacy.</li>
        <li><b>Geospatial Hazard Mapping</b> — Dynamic PostGIS danger-zone radius calculated from real-time BMKG earthquake data.</li>
        <li><b>Ring Dispatch &amp; Escalation Engine</b> — Tiered volunteer coordination based on proximity &amp; readiness score with automated timeout escalation.</li>
        <li><b>Offline-First Synchronization</b> — Idempotent batch sync designed for field volunteers operating in zero-connectivity areas.</li>
        <li><b>Production-Grade Architecture</b> — 69+ automated tests, JWT + RBAC authentication, fully containerized with Docker, paired with a native Kotlin (Jetpack Compose + osmdroid) mobile app.</li>
      </ul>
      <p align="center" style="margin-top: 12px; margin-bottom: 4px;">
